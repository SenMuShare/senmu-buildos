# 源码公开边界

Senmu BuildOS 使用“私有权威库 -> 白名单公开投影 -> GitHub”的单向发布链。公开投影是可重建的源码发布单元，不是第二个日常开发 owner。

## 公开内容

- 插件元数据、八个 Skill、Harness 适配、Hooks 和 CLI。
- 用户需要的架构文档、使用说明、贡献规则、许可证、公开验证脚本与测试。
- 版本和 Changelog。

## 不公开内容

- 内部任务、工作日志、原始反馈、未发布计划和内部审查证据。
- 用户名、本机绝对路径、安装缓存位置、私有项目名和运行数据。
- 密钥、令牌、本机配置和任何未在公开白名单中的文件。

## 门禁

发布过程从冻结的内部候选生成公开投影，检查白名单、禁止路径、私有标识、绝对路径、公开 diff 和完整测试。任一门禁失败时保留上一个公开版本，不推送部分结果。

当安装方式、部署目标、构建工具、制品类型或仓库边界变化时，它们首先触发能力复评；只有存在真实消费者和发布契约时，才新增制品目录与生命周期。
