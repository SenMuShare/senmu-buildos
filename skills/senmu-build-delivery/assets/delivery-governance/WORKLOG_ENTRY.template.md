# Work Log Entry Templates

只复制当前场景需要的变体，并删除不适用字段；不得用占位模板冒充已发生事实。

## 完成一次开发、修复或治理变更

```markdown
## <日期时间> - <执行者> - <分支／任务>

### 任务
- <目标与范围>

### 修改
- <文件／对象与实际变化>

### 决策
- <关键取舍及理由>

### 验证
- <实际命令、环境、结果或回执>

### 文档影响
- <已更新的权威文档；或已审阅且继续适用的发布单元／版本>

### 未验证与风险
- <未执行项、影响和残余风险>

### 复盘
- <是否触发复盘、经验 ID 或不提升原因>

### 下一步
- <未完成项、触发条件和接力入口>
```

## 中断任务

```markdown
## <日期时间> - <执行者> - interrupted - <分支／任务>

### 任务
- <目标与范围>

### 已完成
- <已落盘且可验证的结果>

### 未完成
- <尚未完成或未验证的事项>

### 中断原因
- <阻断事实及影响>

### 下一步
- <恢复入口、所需条件和首个动作>
```

## 正式发布或回滚

```markdown
## <日期时间> - <执行者> - release <发布单元与版本>

### 发布
- 发布单元：<名称>
- 版本／tag／commit：<固定身份>
- Remote／PR／MR／平台 Release：<真实状态或不适用原因>

### 部署与制品
- 目标环境／服务：<实际对象>
- 制品／镜像／SHA：<不可变身份>

### 生产验证
- <运行对象、版本接口、健康状态和受影响主流程>

### 收口
- <VERSION、Changelog、Release Record、文档适用版本、保留策略和回滚点>
- 未发布改动／未验证项：<无或实际范围>
```
