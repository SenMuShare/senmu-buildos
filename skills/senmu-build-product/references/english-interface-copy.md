# Interface Copy: English Profile

This profile contains only English-specific decisions. Apply the shared interface-content specification first; do not duplicate its universal rules here.

## 1. Grammar and labels

- Use natural active voice and address the user directly when needed. Keep the project's choice of tone, contractions, and terminology consistent.
- Use sentence case for buttons, labels, headings, and menu items by default. Preserve product names and established acronyms; follow a platform or brand override only when it is explicit and consistent.
- Avoid all caps, unnecessary title case, stacked nouns, and nominalizations that make an action read like a document heading.

## 2. Inflection and localization

- Keep number, plurality, articles, tense, pronouns, and variable order grammatically correct. Do not build user-facing sentences by concatenating fragments.
- Localize the intent and outcome, not the source words. An English label may need a different structure from the Chinese label and does not need to match its character count.
